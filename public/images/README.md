# Image Folder Guide

Use this folder as the single public image entrypoint.

## Structure

- `site/`
  - Website-owned brand assets
  - `brand/`: logo, favicon source, brand marks
  - `mascot/`: mascot and character artwork
- `partners/sponsors/`
  - Sponsor logos used by the partners page
- `partners/clubs/`
  - Club logos used by the partners page

## Notes

- Files in `public/` are served directly from the site root.
- Example:
  - `public/images/partners/sponsors/devcore.png`
  - URL: `/images/partners/sponsors/devcore.png`
- Current site assets:
  - `public/images/site/brand/logo.png`
  - `public/images/site/brand/logo.ico`
  - `public/images/site/mascot/uwu.png`
